# 开发与版本变更日志

## V1.1.4 完整开发版 · 2026-11-23

本版以 `24ba2ff` 为代码基线，统一了双模式检索、后续三项修复和 WP00–WP14 已交付的功能。源码、示例配置、数据库迁移、测试、部署脚本和文档由 Git 管理。实际 NAS 配置、凭据、SQLite 业务库和运行日志由各环境管理。版本交付见 [PR #18](https://github.com/OmNell/AI-for-Design-Assets/pull/18)，启动步骤见 [README](../README.md#开发环境)。

### 当前功能

| 模块 | 当前可以做什么 |
| --- | --- |
| 登录与权限 | 使用真实群晖 DSM 账号登录，程序用同一操作者的 SMB 会话访问 NAS。不同设备的会话独立。工作台按上传、初审、终审、管理员角色显示入口。开发模式使用示例账号、模拟 NAS 和 Fake AI。 |
| NAS 连接与资产浏览 | 管理员可以测试连接、核定工作根目录并查看正式区、临时区和备份区。资产浏览可在已入库资产和 NAS 实时目录之间切换，支持文件树、筛选、预览和授权下载。 |
| 入库上传 | 拖入或选择项目文件夹，查看预检结果后分片上传。支持暂停、断点续传、正式文件完整 SHA-256、历史 H 项目编号和同项目在途互斥。终止后保留批次和临时文件，由管理员按流程清理。 |
| 主图与人工核对 | 在上传暂存后为每张单品或套装主图填写预描述，再生成 AI 标签和套装关系建议。上传人逐项确认固定 11 个标签、处理异常提示并确认套装关系。提交审核时冻结本轮快照。 |
| 两级审核 | 初审和终审通过独立待办领取，可在图片上标注意见、驳回和查看历史。终审核定最终目录。通常要求提交、初审、终审三方独立，配置指定账号的本人首次入库例外见下方变更记录。 |
| 正式入库与项目浏览 | 终审通过后按检查点执行文件移动、三层档案、商品记录和永久链接。必要向量生成通过后发布。项目、商品和文件页面支持预览、下载及历史记录查看。 |
| 智能检索 | 默认「快速匹配」，在 SQLite 查询编号、名称、标签和描述等内容。可切换「AI 自然语言搜索」，使用语义召回与排序。两种模式共用筛选、结果卡片和权限检查。管理员可管理正式和候选向量索引。 |
| 入库后操作 | 支持补充资料、替换主图、编辑信息、移动、作废和恢复。涉及正式资产的操作按流程双审，保留历史版本。物理删除受最短 30 天冷静期及审核约束。 |
| 运维与部署 | 管理后台提供巡检、备份、档案修复、任务和异常记录、日志查看或导出、终态临时区清理。仓库提供 Windows 候选部署、升级回退、自检及恢复工具。 |

### 本次修改

| 改动 | 现在的行为 |
| --- | --- |
| 快速匹配与 AI 自然语言双模式 | 快速匹配无需调用模型或读取向量数据，显示名称、编号或标签等命中依据。AI 模式保留语义召回、排序和降级提示。切换模式保留输入与中标状态、行业、企业筛选。 |
| 文件夹选择反馈 | 选择文件夹后显示授权、读取和预检进度。遇到取消、读取失败或浏览器限制时提示原因，并提供重选、普通选择或拖入入口。支持完整目录读取的浏览器会保留空目录。 |
| 指定管理员首次入库自审 | `review.self_review_admin` 默认为空。启用后，只有匹配真实登录名且持有管理员和对应审核角色的账号，才可依次初审和终审本人上传、本人提交的首次入库。两级分别领取和通过，并保留审核清单、快照、权限校验和操作日志。 |
| 全局排版及结果标签 | 搜索商品的长中文标签、连续编号和英文可在卡片内换行，网格和列表均保留全文。上传、预描述、审核、资产浏览等页面按工作区宽度调整分栏。较窄时详情使用弹窗，宽表格在自身区域内滚动。 |

### 数据库与兼容

- V1.1.3 的迁移 `0021_pre_descriptions` 新增主图预描述及其版本、文件指纹和识别证据字段；已提交的审核快照与正式资产沿用原记录。
- V1.1.4 的迁移 `0022_dual_search` 增加搜索模式及相关索引，历史搜索日志保留原 AI 检索模式。目录选择、自审配置和排版修复沿用这一迁移版本。
- 升级已有环境前备份 SQLite、配置与密钥。新环境安装项目依赖并构建前端后，可用示例配置启动开发模式。连接真实 NAS 需要该环境自己的配置、账号权限和必要凭据。
