# 开发与版本变更日志

## V1.1.9 · 2026-11-27

- 具备对应审核角色的上传人、发起人或提交人可审核本人批次，适用于首次入库、作废及其他入库后操作，也适用于已有待审批次。
- 同轮初审和终审须由不同账号完成。审核队列、待办、领取、审批和正式执行采用同一规则，并保留审批记录与快照校验。

- 换机与故障恢复补齐备份核验、隔离暂存、档案增量恢复、备份写入条件、停机切换和回滚。恢复保留可核验的项目、商品及文件身份和永久链接。[数据存储与向量关系](05-数据存储与向量关系.md) · [部署手册](../deploy/README.md#数据恢复)
- 检索说明补齐快速匹配的零模型调用路径、AI 语义检索的候选规则、正式向量索引补齐与缩略图重建。[检索方案](04-检索方案.md) · [数据存储与向量关系](05-数据存储与向量关系.md)
- 真实群晖权限和多设备会话、百炼模型以及 Windows 停机切换与回滚仍待现场验收。[设计差异与现场验收记录](QUESTIONS.md)

## V1.1.7 · 2026-11-26

V1.1.7 源码通过 GitHub 默认分支 `main` 交付，包含 V1.1.5 之后的 SMB 原生认证和跨环境资产恢复。后端健康接口及前端包的版本为 `1.1.7`，Windows 构建默认候选为 `v1.1.7-rc.1`。

- 生产登录使用本人签名 SMB 会话，沿用设备隔离、工作台角色和 NAS 文件权限。V1.1.5 的 DSM 配置键可随旧配置读取，既有有效的 NAS、AI 和数据目录配置继续生效。
- 管理后台新增「资产恢复与索引管理」。有有效备份时可核验并暂存数据库，同时生成 NAS 差异报告。仅有正式 NAS 档案时，可按确认的计划增量恢复稳定身份、确认标签、套装关系、历史版本和原永久链接。
- 恢复使用原有 SQLite、档案、发布凭据和向量索引机制。存在未完成业务或证据冲突时，报告具体原因供人工核对。有效向量和缩略图可复用，缺失项支持重建。
- 新部署和隔离恢复配置支持只读核验。生产备份受资产状态保护，正式入库及资产变更后可启用延迟合并备份。Alembic 头保持 `0023_nas_access_audit`，早期备份在隔离目录迁移。
- 发行范围、配置兼容与自动化验收见 [V1.1.7 专项交付报告](V1.1.7-专项交付报告.md)。Windows 现场部署、群晖真实账号与权限、百炼实际模型仍需在授权环境验收。

## V1.1.5 · 2026-11-26

本版收录 V1.1.4 完整开发版之后的改动，包括 WP01–WP14 核对后的补修及 WP12 审核界面更新。源码以 GitHub 默认分支 `main` 交付。后端健康接口和前端包版本使用 `1.1.5`，Windows 构建脚本默认使用候选版本 `v1.1.5-rc.1`。

| 模块 | 更新内容 |
| --- | --- |
| 分片上传 | 原浏览器上已开始的上传在 SMB 连接健康时可跨过工作台登录自然到期。主动退出或 NAS 断线后，重新登录可按已确认偏移续传。不同批次可并行写入，确认上传前会按企业标准名或别名显示建议归档目录。普通文件夹选择未提供空目录时，页面提示可改用拖入。 |
| 人工核对 | 标签输入建议同时参考本批次和当前账号有权限读取的正式项目，保留 11 个字段逐项确认和自由文本输入。 |
| 两级审核与待办 | 待初审和待终审的「驳回」移到页首，在标签页也可找到。由本轮领取人填写总体意见后提交，上传人重提从初审开始。队列标出指定账号适用的首次入库自审例外，待办增加入库完成和 AI 停滞提醒。 |
| 正式入库与灾难恢复 | 通过档案、文件及向量检查后，先写入并读回 NAS 恢复凭据，再提交 SQLite 可见状态。写入中断可由本轮终审继续。巡检可报告旧档案缺失或不匹配的凭据，从可用的 SQLite 发起双审修复。 |
| 项目展示与文件审计 | 套装卡片可展开关联单品，商品卡可直接复制永久链接。授权后主图无法解码时返回占位图。NAS 实时文件浏览记录主动预览，并把同次下载的 Range 请求归为一条访问记录。 |
| 双模式检索 | 登录默认入口按角色区分，上传人进入工作台首页，其余账号进入智能检索，经永久链接登录仍回到原资产。考卷工具可用同一题库对比快速匹配和 AI 模式的召回、排名、耗时与模型调用。 |
| 入库后操作（WP12） | 上传人核对页和审核页显示新增、替换、跳过数量，另存计入新增。可按冻结版本并排查看新旧商品主图和被替换的 JPG、PNG 资料图片。其他文件可对比大小、时间和完整 SHA-256。预览使用当前账号的 NAS 会话，检查上传副本的指纹并写访问记录。 |
| 巡检 | 支持按北京时间的起止日筛选巡检记录和异常，运行报告可分页查看。 |

### 升级与兼容

- 从迁移 `0022_dual_search` 升级时，`0023_nas_access_audit` 为 `access_logs` 增加两个可空字段，记录实时 NAS 的相对路径和已发送字节区间。原有记录保留。需要回退时使用升级前的备份恢复。
- WP12 的文件对比直接读取已有审核快照，无需重新提交待审批次。资料预览需要本人相应的 NAS 读取权限。图片超过 48 MiB、无法解码或临时文件已清理时，页面仍提供文件元数据。
- 本次提交包含源码、迁移、测试及部署文档。前端产物由部署环境按 README 构建。升级前请备份 SQLite、配置和密钥。

## V1.1.4 完整开发版 · 2026-11-23

本版以 `24ba2ff` 为代码基线，统一了双模式检索、后续三项修复和 WP00–WP14 已交付的功能。源码、示例配置、数据库迁移、测试、部署脚本和文档由 Git 管理。实际 NAS 配置、凭据、SQLite 业务库和运行日志由各环境管理。版本交付见 [PR #18](https://github.com/OmNell/AI-for-Design-Assets/pull/18)，启动步骤见 [README](../README.md#开发环境)。

### 当前功能

| 模块 | 当前可以做什么 |
| --- | --- |
| 登录与权限 | 使用真实群晖 DSM 账号登录，程序用同一操作者的 SMB 会话访问 NAS。不同设备的会话独立。工作台按上传、初审、终审、管理员角色显示入口。开发模式使用示例账号、模拟 NAS 和 Fake AI。 |
| NAS 连接与资产浏览 | 管理员可以测试连接、核定工作根目录并查看正式区、临时区和备份区。资产浏览可在已入库资产和 NAS 实时目录之间切换，支持文件树、筛选、预览和授权下载。 |
| 入库上传 | 拖入或选择项目文件夹，查看预检结果后分片上传。支持暂停、断点续传、正式文件完整 SHA-256、历史 H 项目编号和同项目在途互斥。终止后保留批次和临时文件，由管理员按流程清理。 |
| 主图与人工核对 | 在上传暂存后为每张单品或套装主图填写预描述，再生成 AI 标签和套装关系建议。上传人逐项确认固定 11 个标签、处理异常提示并确认套装关系。提交审核时冻结本轮快照。 |
| 两级审核 | 初审和终审通过独立待办领取，可在图片上标注意见、驳回和查看历史。终审核定最终目录。通常要求提交、初审、终审三方独立，配置指定账号的本人首次入库例外见下方变更记录。 |
| 正式入库与项目浏览 | 终审通过后按检查点执行文件移动、三层档案、商品记录和永久链接。必要向量生成通过后发布。项目、商品和文件页面支持预览、下载及历史记录查看。 |
| 智能检索 | 默认「快速匹配」，在 SQLite 查询编号、名称、标签和描述等内容。可切换「AI 自然语言搜索」，使用语义召回与排序。两种模式共用筛选、结果卡片和权限检查。管理员可管理正式和候选向量索引。 |
| 入库后操作 | 支持补充资料、替换主图、编辑信息、移动、作废和恢复。涉及正式资产的操作按流程双审，保留历史版本。物理删除受最短 30 天冷静期及审核约束。 |
| 运维与部署 | 管理后台提供巡检、备份、档案修复、任务和异常记录、日志查看或导出、终态临时区清理。仓库提供 Windows 候选部署、升级回退、自检及恢复工具。 |

### 本次修改

| 改动 | 现在的行为 |
| --- | --- |
| 快速匹配与 AI 自然语言双模式 | 快速匹配无需调用模型或读取向量数据，显示名称、编号或标签等命中依据。AI 模式保留语义召回、排序和降级提示。切换模式保留输入与中标状态、行业、企业筛选。 |
| 文件夹选择反馈 | 选择文件夹后显示授权、读取和预检进度。遇到取消、读取失败或浏览器限制时提示原因，并提供重选、普通选择或拖入入口。支持完整目录读取的浏览器会保留空目录。 |
| 指定管理员首次入库自审 | `review.self_review_admin` 默认为空。启用后，只有匹配真实登录名且持有管理员和对应审核角色的账号，才可依次初审和终审本人上传、本人提交的首次入库。两级分别领取和通过，并保留审核清单、快照、权限校验和操作日志。 |
| 全局排版及结果标签 | 搜索商品的长中文标签、连续编号和英文可在卡片内换行，网格和列表均保留全文。上传、预描述、审核、资产浏览等页面按工作区宽度调整分栏。较窄时详情使用弹窗，宽表格在自身区域内滚动。 |

### 数据库与兼容

- V1.1.3 的迁移 `0021_pre_descriptions` 新增主图预描述及其版本、文件指纹和识别证据字段；已提交的审核快照与正式资产沿用原记录。
- V1.1.4 的迁移 `0022_dual_search` 增加搜索模式及相关索引，历史搜索日志保留原 AI 检索模式。目录选择、自审配置和排版修复沿用这一迁移版本。
- 升级已有环境前备份 SQLite、配置与密钥。新环境安装项目依赖并构建前端后，可用示例配置启动开发模式。连接真实 NAS 需要该环境自己的配置、账号权限和必要凭据。
