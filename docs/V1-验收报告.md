# V1.0 候选验收报告

当前交付为 **v1.0.0-rc.1**。Windows 服务、公司内网真实群晖和百炼未获得现场验证。规则 #02 的上传令牌行为和旧档案恢复证据是正式上线的阻断项。正式发布须经公司验收和批准。

- 开发基线为 WP13 `d3e0c377ce195d47ba7a4633dc39e2365851cc67`。PR #2–#9 开始实施时仍开放，WP14 PR 目标为 `codex/wp13-inspection-backup-admin`。
- 开发演练使用 macOS 27.2.1、Apple M5 Pro、24 GiB 内存、Python 3.12.16、Node 22.23.5、npm 10.9.9。数据库、NAS 与网络使用隔离 SQLite、LocalFs、Fake AI 和环回测试服务。
- 自动回归共 320 个后端用例通过，16 个真实 NAS／百炼用例按配置排除。前端 20 个文件、105 个测试通过。TypeScript 检查与 Vite 生产构建通过。已有 Starlette TestClient 弃用提示及 Vite 主包约 512 kB 的大小提示。
- Alembic 单一 head 为 `0020_maintenance`，WP14 不新增数据库迁移。隔离副本从 `0004_ai` 升级成功，保留既有行 ID 并通过外键检查。合成旧库从 `0011_p0_device_sessions` 升级到 `0020_maintenance`，再由升级前备份回到 `0011`，核对了原用户 ID、角色及密钥。回滚使用一致性快照，从未对生产数据库执行降级。
- 五份 PowerShell 脚本通过语法树检查（构建、安装、公共函数、升级、卸载）。NSSM 注册、LocalService ACL、开机自启、断点升级及防火墙变化需要 Windows 实机操作。
- 候选 ZIP 由锁文件构建，包含发布版本、构建时间、源提交及逐文件 SHA-256。校验器的测试拒绝哈希不匹配、越界路径和私密文件。ZIP 及整包 SHA-256 位于本次交付的 `dist/`。只应从已核验的解压目录执行脚本。

## 恢复演练

### A · 存在数据库快照

从运行中应用的隔离 SQLite 制作一致性快照，停止引用后模拟错误更新再恢复。日志记录的快照及故障回滚用时约 0.016 秒。通过的对照项包括项目及文件身份、短链、角色、审核记录、现用向量 BLOB 和正式模型索引指针。原 WP13 备份回归也从备份 ZIP 恢复配置及密钥，在新目录启动并解析原链接。迁移回退单独验证同一用户在 `0011` 和 `0020` 的角色。实际 NAS 备份容量、备份包传输及大库恢复用时待测。

### B · 数据库和全部备份丢失

仅从模拟正式 NAS 扫描、核验档案及原文件 SHA-256，在新目录迁移并重建。首次置为隐藏，缩略图生成后以既有必要向量门禁恢复可见性。模拟项目从扫描到原短链和搜索可访问约 0.14 秒。关系样本比较 2 条跨商品关联、33 条固定字段及原 ID／短链。注入向量调用失败后，项目仍为 `ingesting`。注入 SQLite 发布前中断时，恢复工具不会把已在正式共享区出现的目录误选为最新，也不会自动回退到上一版。

旧档案或最新候选缺少发布凭据时，保留人工核实项。不可恢复范围包括原登录会话、角色授权、完整审核台账、操作与访问日志、任务历史、原候选模型、完整企业行业对照表及无档案证据的预期删除或审批。角色从空库重新核准，原短链数据保留。只有通过验证的资产可纳入恢复切换。

## 性能记录

以下为本地回归实测。应用进程启动、NAS 传输、真实 AI 并发和典型生产数据规模另行计时。

| 指标 | 隔离测试观测值和口径 |
|---|---|
| 应用启动 | 约 6.1 毫秒，恢复库 TestClient 生命周期启动 |
| 登录、项目列表、商品详情 | 分别约 5.0、8.8、4.3 毫秒，一次本机 API 调用 |
| 上传和完整 SHA-256 | 16 MiB 分片接收约 1106 MiB/s，读取并计算完整哈希约 10.5 毫秒。本机合成数据及缓存，不作为 NAS 吞吐 |
| 2 GiB 流式下载与断点 | 本机整条传输及指纹验证用例约 3.77 秒，独立 Range 用例验证续读、越界及请求账目 |
| 搜索平均与 P95 | 12 次本机请求分别约 4.60、6.02 毫秒。10 条模拟考卷平均 8.51、P95 15.46 毫秒，召回和 Top 3/10 为 100%，真实考卷未执行 |
| AI 和任务恢复 | Fake AI 的毫秒级计数为 0。覆盖故障、超时、重试、降级及强行结束服务后的任务续跑，单次续跑集成用例约 0.91 秒 |
| 20 张主图三档 | 上传完成后约 0.21 秒生成及访问 |
| 巡检 10,000 个稳定文件 | 用例内约 1.85 秒，巡检记录 1722 毫秒，未重算稳定文件指纹 |
| 多设备并发会话 | 验证同账号设备独立、退出隔离、会话失效处理和恢复 |
| 快照和恢复 | A 小库约 0.016 秒，B 单项目约 0.14 秒。详见两种演练 |
