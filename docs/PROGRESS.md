## WP02 · NAS 文件接口与会话池

- 日期：2026-11-16。

### 已完成

- `backend/app/services/nas/fs.py` 定义 NasFs 协议与 NasStat，实现所有规定方法、流式异常转换和生命周期管理；支持追加、偏移读、递归建目录及显式递归删除。
- `LocalFs` 根据用户区域权限表执行只读/读写/无权限模拟；默认根 `./devdata/nas` 来自配置。`SmbFs` 使用本人凭据、独立连接缓存及 SMB 连接，不挂盘、不借用系统身份。
- 三个区域根均来自配置；安全拼接拒绝路径穿越、绝对路径、非法名称和区域外访问，禁止删除/改名区域根；拒绝链接/重解析点。重命名检查源与目标权限，只用 rename，不退化复制。
- 统一四类文件异常；SMB 按 NTSTATUS 优先分类，共享冲突不能误判为权限拒绝。错误不返回上游请求对象和认证材料。
- SessionPool 提供 open/get/close/system、后台空闲回收与 shutdown，支持上下文管理；用户会话过期抛 NasSessionExpired 并要求重新登录。实例操作和池操作分别上锁，活动流阻止空闲回收。
- FakeAuthBackend 从 dev_users 读取假账号、密码与权限；DsmAuthBackend 发现接口后 POST 登录，成功立即 POST 注销，不保留用户凭据或 SID，认证拒绝与服务不可用分别处理。
- 模式工厂提供验证后端、用户文件会话、系统文件会话及会话池；prod 系统账号从 Fernet 密文解密，dev 使用 LocalFs。系统权限固定为正式只读/备份读写/临时无权限，并仍受 NAS ACL 限制。
- 配置示例与 README 已补齐 dev_users、dev_nas_dir、idle_minutes、timeout_s、受信 CA，以及两个测试账号的环境变量运行方式。根 pytest 配置统一管理 nas/bailian 默认排除。
- 本包没有登录或上传 API，没有新数据库表/迁移，没有前端业务改动。工厂由后续调用者显式创建，启动 health 不会访问真实 NAS。

- lite 模式下导航、顶部信息条、弹窗和主要按钮按界面约定仍是实时玻璃；无 GPU 环境下它们决定了帧率下限。

## WP07 补充修复 · 液态玻璃与官方样例不一致

- 日期：2026-11-16；按用户追加要求，只处理玻璃效果，不涉及业务逻辑。
- 根因一（渲染错误）：屏幕缩放不是 100%（高分屏、Windows 125%/150%、浏览器缩放）时，Chromium 的位移滤镜读取 liquid-glass-react 自带贴图不随缩放放大，贴图只盖住左上角一部分，其余区域整体平移，出现右侧和底部的深色条带且四边没有折射。按官方 README 原样使用该库同样复现，不是封装引入的。
- 修复：`GlassSurface` 在挂载、尺寸变化和缩放变化后，把库生成的 feImage 尺寸按「设备像素比向上取整」放大（0.8～3 倍逐档实测：1.1/1.25/1.5/2 用 2，2.5/3 用 3）。偏大只会让边缘折射略弱，不会产生条带。
- 根因二（封装削弱了效果）：原封装自定了折射强度、饱和度和模糊，去掉了库的投影，又盖了一层白底和白边，加上页面底色近乎纯色，折射无物可折，看起来只是半透明白板。
- 修复：折射、模糊、饱和度、色散改用库默认值（即官方样例参数），恢复高光描边与投影（嵌套的小块投影收小）；页面底色改为固定的多色光斑，玻璃边缘能看到背后颜色被弯折。仍关闭弹性位移，保证文字层不跟着晃动。
- 列表项：位于可滚动容器内的条目挂折射滤镜会渲染成灰块，`GlassListItem` 在 full 模式改为半透明加背景模糊，lite 模式仍不做任何实时滤镜。
- 验证：前端 81 项测试通过（新增缩放倍数用例）、构建成功；无头 Chromium 在 1、1.25、1.5、2 倍缩放下截图核对组件样例页与核对页，条带消失、四边折射正常。
- 已知限制：官方在线演示站点在本环境无法访问，对照依据是仓库 README 的样例图和 README 写法的本地复现；本环境无 GPU，未在真实显卡的 Chrome/Edge 上确认，取整规则是对当前 Chromium（153）的实测结论，浏览器行为变化时需复测。Safari/Firefox 仍按库的说明回退为 CSS 毛玻璃。

### 已知限制

- 断点续传只用 curl 验证了协议行为（Range + If-Range + ETag）；浏览器下载管理器的「继续」未在真实浏览器里手动点过。
- 下载走的是工作台进程中转（NAS → 工作台 → 浏览器），速度受工作台所在电脑的网络和 SMB 读取速度限制；本机 LocalFs 的速度不代表 NAS。
- 四层查找的第二层只在「中标状态/行业/企业/项目」这一固定层级里找，项目被移到别的层级找不到；第四层要对同大小的候选逐个算指纹，大文件多时会慢。查找用的是当前用户的 NAS 权限。
- 卡片柜里的项目、商品信息对所有登录用户可见，不受 NAS 权限限制；只有读取文件内容（下载、重建缩略图）跟随 NAS 权限。已有本地缓存的缩略图同样对所有登录用户可见。
- 多段 Range 不支持（按整文件返回）。批量下载是页面逐个触发，浏览器可能提示「允许下载多个文件」，需要用户允许一次。
- 无头浏览器在没有 UTF-8 语言环境的系统上会把中文文件名显示成 download，这是测试环境的现象；设置 UTF-8 环境后文件名正确。
- 入库后操作按钮只是禁用占位；历史版本目前总是空的；语义搜索不在本包。
