## Tailwind 规范与共享组件

Tailwind 保持 3.4，基于官方应用 UI 的侧栏、多列、数据表格、表单、描述列表和对话框模式自主实现。[Tailwind Application UI](https://tailwindcss.com/plus/ui-blocks/application-ui) · [响应式布局规则](https://tailwindcss.com/docs/responsive-design)

- `frontend/src/style.css` 管理页面与共享样式。使用 slate-50 底色、白色面板、slate-900／500 文字、slate-200 边框、blue-600 主操作，以及 emerald、amber、red 语义状态。正文 14px，辅助信息 12px，页面主标题 20–24px。输入焦点环、键盘轮廓及 4px 间距尺度统一。
- `components/ui` 提供 Button、IconButton、Input、Select、Textarea、Checkbox、Badge、Card、Panel、ListItem、Table、Dialog、Breadcrumb、EmptyState、LoadingState、ErrorState、Pagination、ViewSwitch、FileIcon、FileThumbnail、ContextPane 和线性 Icon。图标按钮带可访问名称。原生 Dialog 管理模态焦点和 Escape；关闭后回到触发点。项目内容标签支持方向键。
- 详情面板在桌面可收起；工作区较窄时从详情入口打开抽屉。长文件名在密集列表中显示两行，完整名称、路径和日期出现在侧栏。过宽资料表格只在容器内部滚动。
- 删除 `components/glass/` 全部实现和旧模式专属测试，包含 GlassProvider、GlassSurface、GlassNav、GlassPanel、GlassCard、GlassButton、GlassListItem、GlassModal、ModeSwitch 及视觉偏好存储。依赖和 React peer override 从包清单与锁文件移除。保留 React 18、Tailwind 3.4 和原业务库。

## 验证记录

- `npm ci`、Vitest 96 项、TypeScript、Vite 生产构建通过。旧视觉模式测试随对应功能退场，替换为弹窗焦点、本地长列表及资产浏览交互回归。
- 后端 pytest 320 项通过，16 项真实 NAS／百炼测试按默认配置排除。后端及迁移无提交变更。
- 使用 macOS 桌面 Chrome 和 Edge 实际可执行文件运行 1280、1440、1920px 浏览器交互检查，复核截图。覆盖分类树、长文件名、详情收起、文件多选、真实权限检查与下载、复制并回跳永久链接、列表／缩略图、搜索匹配、角色守卫和审核只读。
- Chrome 另跑通文件夹预检、分片上传、Fake AI、11 个字段逐项确认、提交人回避、两个独立账号逐级审核及最终正式入库。
- 截图保存在工作区 `dist/ui-review/`，来自通过开发模式真实接口生成的隔离测试数据。文件名包含浏览器、宽度和页面。其中 `dashboard`、`assets-file`、`products`、`upload`、`review`、`audit`、`search`、`admin` 为主要复核画面。

## 现有接口边界

- 历史版本清单只提供原文件 ID 与路径，界面继续使用原文件详情入口。普通资料在缩略图模式中使用类型图标，商品显示已生成的缩略图，文件图片可由用户主动申请授权预览。
- 目录浏览来自现有目录和已登记文件的相对路径。五个标准资料夹可显示为空；现有项目 API 未列举完全空的任意深层目录。
